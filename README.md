# Vlex eSIM — демонстрационный прототип

Адаптивный статический прототип проверки eSIM. Откройте `index.html` в браузере или разместите содержимое папки в корне GitHub Pages. Сборка, зависимости, сервер, токены и внешние запросы не нужны.

## Сценарий
Выберите модель, регион покупки и страну поездки. Кнопка показывает «Подтверждено в демо-базе» либо «Неизвестно». Список комбинаций в `app.js` иллюстративный и не является проверенной базой производителя. «Подтверждено» относится **только к демо-базе**, не гарантирует совместимость конкретного устройства. Для неизвестных комбинаций отсутствие записи не означает отсутствие поддержки. Страна не проверяет покрытие или наличие тарифов.

Кнопка тарифов демонстрационная: каталог не подключён, цены и ссылки на сервис не выдуманы. Все данные остаются в браузере. Перед реальным применением необходимо заменить демо-базу проверенными данными и согласовать юридические формулировки.
